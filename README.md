# Live-Stock-Market-Data-Analysis

Project Overview

This project analyses stock market data using Python and financial market data from Yahoo Finance through the yfinance library.

Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Yahoo Finance API (yfinance)

Project Features

- Fetch historical stock market data
- Data cleaning and preprocessing
- Stock closing price analysis
- Daily trading volume analysis
- High vs Low price comparison
- Moving Average calculation
- Daily Returns analysis
- Profit and Loss calculation
- Stock volatility analysis
- Matplotlib visualizations and subplot dashboard

Installation

pip install yfinance pandas numpy matplotlib
